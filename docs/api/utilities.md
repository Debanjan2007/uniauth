# Utilities

UniAuth provides essential utility functions to handle OAuth flows, especially PKCE.

## Exported Utilities

### `ExtractKey(url: string)`

Parses the authorization URL generated by PKCE-enabled providers (Google, GitHub) to extract the unique `key` parameter and the clean authorization URL.

**Purpose**: Providers using PKCE generate a dynamic `code_verifier` and store it in memory. A temporary `key` is appended to the generated auth URL so the developer can extract it, store it in the user's session/cookie, and then redirect the user to the cleaned URL.

**Parameters:**
- `url` (`string`): The raw authorization URL returned by `provider.getAuthorizationUrl()`.

**Returns:**
An object containing:
- `key` (`string`): The unique key to retrieve the stored `code_verifier`.
- `AuthUrl` (`string`): The clean OAuth authorization URL to redirect the user to.

**Example:**

```typescript
import { ExtractKey } from '@deba_1307/uniauth';

const rawUrl = googleProvider.getAuthorizationUrl();
const { key, AuthUrl } = ExtractKey(rawUrl);

// 1. Store 'key' in session or cookie
req.session.pkceKey = key;

// 2. Redirect to AuthUrl
res.redirect(AuthUrl);
```

## Internal Utilities (For Contributors)

These utilities are used internally by the library and are documented here for contributors and advanced users understanding the architecture.

- **`generateCodeVerifier()`**: Generates a cryptographically random code verifier for PKCE.
- **`generateCodeChallenge(verifier)`**: Hashes the code verifier using SHA-256 to create the code challenge.
- **`useMemory(key, value, ttl)`**: Stores a key-value pair in memory with a Time-To-Live (TTL). Used for storing PKCE verifiers (60s TTL).
- **`getMemory(key)`**: Retrieves a value from memory and removes it (one-time use).
- **`generateAuthUrl(...)`**: Shared helper to construct standard OAuth authorization URLs.
- **`ExchangeCodeforToken(...)`**: Shared helper to perform the HTTP POST request exchanging the code for tokens.
- **`getUserProfile(...)`**: Shared helper to fetch the user profile from the provider's API.
- **`refreshToken(...)`**: Shared helper to perform the refresh token flow.
